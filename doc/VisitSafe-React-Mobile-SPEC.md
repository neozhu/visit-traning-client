# VisitSafe React 手机端开发规范

## 目标与范围

依据既有业务需求、中文文案和登记—培训—考试—记录流程，开发独立 React 手机网页。只针对现代手机浏览器，不开发桌面布局。本轮是完整、可交互的本地演示应用，使用模拟课程、视频和浏览器本地持久化；真实认证、跨设备共享、后台审批和门禁属于后续 API 接入范围。

应用位于 `web/`，图标、插图和短视频位于 `web/public/assets/`。根目录提供启动、构建和测试入口；业务与浏览器测试全部针对 React 应用。旧客户端代码、配置、依赖及专用工具已按用户要求移除，历史业务规格和视觉参考保留。

## 技术与视觉

- React、TypeScript、Vite、Ant Design Mobile、Tailwind CSS、React Router，使用当前稳定版本并锁定依赖。
- Ant Design Mobile 负责表单、选择器、弹窗、提示及导航，Tailwind 负责布局；业务组件使用少量独立 CSS。
- 保留科技蓝 `#246BFD`、标题色 `#192B43`、背景 `#F5F7FB`、白色卡片和 14px 圆角；使用系统中文字体和既有 SVG 图标。
- 适配手机宽度 320–430px，支持自然滚动、底部安全区与键盘。按钮可触摸区域不少于 44px；字段有可见标签，错误信息靠近字段。

## 页面与交互

1. 首页：学习培训、普通访客、物流车辆、施工人员四个入口，继续未完成培训入口；底部首页／我的导航。
2. 登记：各类型须知弹窗打开后倒计时 3 秒，倒计时结束且勾选同意后才可确认继续；弹窗适配手机宽度、正文 16px，短屏可内部滚动。登记信息／访问区域／确认提交三步；草稿在刷新及重新进入后保留。
3. 人员与车辆：访客填写姓名、手机号、单位；施工填写姓名、手机号、工种并继承施工单位；物流沿用车辆、司机及运输单位录入。访客与施工支持选填随行车牌。增、改、删、取消操作完整，车牌支持七／八位自定义键盘。
4. 任务：按人员独立创建课程，展示人数及课程进度，支持选择个人或全部人员；按姓名＋手机号和同一课程复用有效的历史通过结果，显示“有效期内免训”、上次通过和有效截止，计入个人合格进度；不能把一人的结果复制给其他人。
5. 继续学习：姓名＋手机号同时精确匹配本人当前需要学习的任务，匹配多个申请分别展示；有效免训课程不出现在待学列表，过期课程生成新轮次；查询不创建登记，也不作为身份认证。
6. 视频：真实播放本地短视频，完成全部片段后才能考试。播放错误明确提示，允许用户主动开启演示计时完成该片段；返回及刷新按已有任务恢复进度。
7. 考试：每门五道单选题，每题 20 分，80 分通过，15 分钟。选答后自动进入下一题，支持修改、答题卡、最终答案评分；主动交卷须答完，到期允许未答题并自动交卷。
8. 结果：成绩、通过状态、错题解析、重新考试及个人培训凭证。失败重考保留本轮视频完成情况，重置答卷与截止时间；已通过且仍有效不重考。免训不伪造视频完成或新成绩，凭证展示历史来源与原有效期；旧学习／考试链接不能绕过免训或继续已过期轮次。
9. 记录：搜索姓名、单位及车牌，查看申请详情、当前个人合格进度，继续学习及确认删除；删除同时移除关联任务，被其他申请复用的来源需先删除关联申请，历史复用不形成申请间依赖环。

## 数据约束

- 预约日期不能为空、必须是真实日历日期且不早于今天；到访时段和事由必须来自给定选项。
- 三类业务信息沿用现有必填要求。访客／施工同一申请内手机号唯一；物流车牌唯一，同一姓名＋手机号的司机只生成一套课程。
- 培训课程通过模拟“登记类型＋区域”组合配置匹配，多个区域课程合并去重；无有效区域或缺少匹配配置时不能提交。
- 每门模拟课程独立配置 trainingValidityDays，默认 60 天，实际通过后保存有效截止；修改课程配置不追溯已有结果。复用结果也必须在预约日开始时仍有效；过期重训保留旧记录和原期限，不沿用旧视频进度。
- 同一草稿重复提交返回同一申请；持久化失败不报告提交成功，也不改写内存状态。
- 考试截止时间和答案持久化。离开、刷新、手机进入后台不能重置截止时间；返回页面按绝对时间计算并交卷。
- 本地存储使用 `visitsafe.web.v2` 命名空间；新版直接清除旧 v1 登记与视频演示计时，不迁移旧数据。新数据的缺损缓存有明确恢复行为，记录仅在当前浏览器可用。
- 后端 SPEC 的动态类型、审批、实际进出厂和审计规则保留供后续接入，不模拟真实审批或通行授权。

## 验收

- 三类登记均走通，访客／施工随行车辆可编辑及取消；刷新恢复草稿，错误提交保留输入。
- 多人、多课程的任务相互独立；精确查询、重载、重考、到期和删除行为有自动化测试。
- 有效历史通过可免训，新增课程与其他人员独立判断；截止时刻、逐课程期限、过期重训、复用不续期、来源删除约束和旧缓存清除有自动化测试。
- 手机尺寸浏览器验收首页、登记、车牌弹层、视频、考试和记录；页面无水平溢出，固定按钮不挡内容。
- React 应用业务测试、类型检查、生产构建和手机浏览器流程均通过。
