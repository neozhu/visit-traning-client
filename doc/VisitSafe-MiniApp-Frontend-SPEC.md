技术要求：
- 微信原生小程序：TypeScript + WXML + WXSS
- 不开发后端，不接入真实 API，不使用云服务
- 使用 Mock Data + 本地 Storage
- 所有页面和业务流程必须真实可交互
- 设计风格简洁、现代、专业，适合制造企业使用
- 保持模块化架构，便于后续接入 ASP.NET Core Web API

请优先完成以下端到端流程：

首页四个入口 → 须知确认 → 多人员/多车辆登记 → 访问区域选择 → 匹配培训方案 → 视频学习 → 在线考试 → 结果展示 → 本地记录查询。

不要只生成静态页面或 UI Demo。

所有新增、编辑、删除、提交、考试评分和重新考试功能都必须实际运行。

严格按照 SPEC 中的验收场景进行自检，确保四种入口都能从头到尾完整演示。
